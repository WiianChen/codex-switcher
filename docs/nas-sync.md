# NAS 同步（開發中，尚未完成實機驗收）

NAS 面板位於帳號清單上方。設定使用 HTTPS 根網址、服務憑證 SHA-256 指紋及一次性配對碼。裝置 Token 寫入 Windows Credential Manager；前端不會收到或儲存 Token。憑證釘選額外檢查一般憑證鏈與主機名稱，沒有略過 TLS 驗證。

先關閉 Codex，再選一個帳號匯入。管理密碼僅供該次 HTTPS 匯入請求，操作後清空。NAS 新帳號預設停用，必須完成 canary 後啟用。NAS 管理的帳號停止 Switcher 的本機 Token 刷新與暖機。

切換流程先同步原帳號，取得目標租約，記錄切換紀錄，再原子寫入本機憑證。成功後釋放舊租約。遇到中斷，關閉 Codex 後按「恢復未完成同步」；恢復以本機 auth 的帳號身分選擇租約，不憑清單目前帳號猜測。

**尚未上線：** 實機配對、TLS 握手負向測試、切換中斷的完整整合測試、Desktop 重載、關機交接與四帳號跨窗驗收仍待完成。不要因編譯通過就啟用排程。

**目前限制：** 心跳逾時仍保留租約，因為 Switcher 關閉不代表 Codex 已停止刷新。突然斷線或 Windows 關機後，最後使用的帳號仍會被 NAS 鎖定；其餘未租用帳號可继续排程。解除這個限制需要可驗證的關機交接，不能單靠 TTL。
